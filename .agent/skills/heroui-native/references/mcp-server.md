# HeroUI Native MCP Server

The HeroUI Native MCP server provides real-time access to component libraries, documentation, and design tokens directly within the agentic environment.

## Available Modules
- `heroui-native`: Core component library and props retrieval.
- `heroui-design-system`: Access to color palettes and typography rules.

## Using the MCP Server
When building complex components, consult the MCP server to:
1. Verify the latest prop signatures for specific components.
2. Retrieve recommended design patterns for navigation and forms.
3. Access production-grade examples of HeroUI Native in action.
